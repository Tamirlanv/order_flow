# Журнал безопасности OrderFlow

[001 — аудит шести пунктов и настройка Nginx](001-audit.md).

Здесь только обезличенные Markdown-отчёты. На каждый пункт: наблюдение, влияние, способ исправления, тест/команда, фактический вывод и оставшиеся ограничения. В одном файле не более 100 проблем с решениями; следующий файл получает следующий номер. Найденная недоработка, отсутствие функции и успешно проверенная защита различаются явно.

Сырые результаты сканеров лежат локально в `.tmp/security/` и не входят в Git. Пароли, ключи, email пользователей, токены и приватные сертификаты в отчёты не копировать. Повторяемые команды — в [README проекта](../../README.md); спецификация — [S01](../../docs/features/006-security-hardening.md).
