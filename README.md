# OrderFlow

Система управления заказами, остатками и доставкой для небольших интернет-магазинов. Дипломный проект с акцентом на Python backend: транзакции, изоляция данных магазинов, фоновые задачи и устойчивые интеграции.

## Текущий статус

Подготовлены требования, архитектура, план, спецификации первых функций и инфраструктурные заготовки. Приложение **ещё не реализовано**. Документы ожидают просмотра владельцем проекта. Реализация начинается только после отдельного указания пользователя.

Контейнеры не запускались. Dockerfile и Compose описывают целевое окружение; сервисы приложения нельзя собрать до этапа M01: исходники и файлы зависимостей пока отсутствуют.

## Планируемый стек

Python 3.12, FastAPI, Pydantic, SQLAlchemy 2, Alembic, PostgreSQL 17, Redis 7.4, Celery 5, RabbitMQ 4, React, TypeScript, Vite. Docker Compose для локального окружения; Kubernetes — отдельное расширение после MVP. Версии Python-пакетов и npm-пакетов фиксируются lock-файлами на M01.

## Подготовка окружения

Команды выполняются из корня репозитория. Для проверки конфигурации нужен Docker Compose v2; работающий Docker Engine не требуется.

```powershell
Copy-Item .env.example .env
# Изменить локальные пароли в .env перед будущим запуском.
docker compose --env-file .env.example config --quiet
docker compose --env-file .env.example --profile app config --quiet
```

Эти команды только проверяют конфигурацию: не собирают образы, не скачивают их и не запускают контейнеры. `.env` с настоящими секретами не коммитить. `.env.example` содержит только публичные демонстрационные значения.

## Будущий запуск — после реализации M01 и отдельного разрешения на контейнеры

```powershell
# PostgreSQL, Redis, RabbitMQ и локальная почта.
docker compose up -d
# После появления исходников и lock-файлов:
docker compose --profile app build
docker compose --profile app run --rm api alembic upgrade head
docker compose --profile app up -d
```

Это целевой порядок запуска, **сейчас он не проверен и не является инструкцией для готового приложения**. Миграции выполняются отдельной командой до запуска приложений. Команды заполнения демонстрационных данных и запуска тестов будут добавлены вместе с их реализацией.

Будущие локальные адреса: интерфейс `http://localhost:8080`, API `http://localhost:8000`, OpenAPI `http://localhost:8000/docs`, почта Mailpit `http://localhost:8025`, панель RabbitMQ `http://localhost:15672`. Порты привязаны к localhost. Пароли берутся из `.env`.

Остановка после будущего запуска: `docker compose --profile app down`. Не добавлять `--volumes`, если нужно сохранить данные.
